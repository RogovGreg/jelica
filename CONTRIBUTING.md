# Contributing to JELICA

External contributions may be merged only after the contributor has completed
the JELICA Contributor Assignment Agreement. The signed agreement must be
submitted through the maintainer channel at <mailto:mail@jelica.bio>.

Opening or submitting a pull request alone does not change the project
license, assign copyright, or grant rights beyond the signed agreement.
Contributors must have the right to submit the code or other material. The
agreement centralizes the copyright and future relicensing ability for
accepted contributions with Grigorii Rogov.

Contributions must not include incompatible third-party code, unapproved
licensed material, credentials, secrets, private data, or generated machine-
specific files. See [`CONTRIBUTOR_AGREEMENT.md`](CONTRIBUTOR_AGREEMENT.md)
for the project agreement template and execution details.
